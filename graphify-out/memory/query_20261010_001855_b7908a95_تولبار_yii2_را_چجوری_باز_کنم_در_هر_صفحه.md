# Q: تولبار yii2 را چجوری باز کنم در هر صفحه

## Answer

برای فعال شدن Yii2 Debug Toolbar در همه صفحات، در app/composer.json بسته yiisoft/yii2-debug وجود ندارد؛ آن را با composer require yiisoft/yii2-debug نصب کنید. در app/web/index.php برای محیط توسعه YII_DEBUG=true و YII_ENV=dev تنظیم کنید. در app/config/web.php ماژول debug را فقط در حالت dev فعال کنید؛ نوار ابزار برای درخواست‌های صفحات به طور خودکار نمایش داده می‌شود. برای دسترسی غیرمحلی allowedIPs را تنظیم کنید. آن را روی production فعال نکنید.
