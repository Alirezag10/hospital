# Q: چرا قسمت ثبت بیمار تاریخ تولد را میلادی می‌گیرد؟

## Answer

Expanded from original query via vocab: [patient, form, persian, format]. The patient form uses ActiveForm input("date") in app/views/patient/_form.php, with max=date("Y-m-d") and an explicit hint saying the date is Gregorian. The Patient model validates birth_date strictly with format php:Y-m-d and max date("Y-m-d"). Therefore the current project deliberately accepts Gregorian dates; the native browser date control also commonly displays Gregorian calendar values according to browser/OS locale. For Jalali entry, add a Jalali date picker and convert its submitted value to Gregorian YYYY-MM-DD before Yii validation and database storage.
