# Hospital

سامانهٔ آموزشی پذیرش، ارائهٔ خدمت و ترخیص بیمارستان، بر اساس صورت پروژهٔ کارآموزی.

## قابلیت‌های برنامه‌ریزی‌شده

- ثبت و فهرست بیماران
- ثبت پذیرش بیمار
- افزودن خدمات به پذیرش و محاسبهٔ هزینه
- ثبت ترخیص و نمایش خلاصهٔ پرونده

## فناوری‌های هدف

PHP و Yii برای برنامه، MySQL برای پایگاه داده، HTML و CSS برای صفحات، و Nginx برای اجرای وب.

## وضعیت پروژه

راه‌اندازی اولیهٔ مخزن در جریان است. برنامه هنوز پیاده‌سازی نشده است. دستورهای نصب، اجرا و تست پس از انتخاب و راه‌اندازی نسخه‌های ابزارها به این راهنما اضافه می‌شوند.
