# سامانه پذیرش، خدمات و ترخیص بیمارستان

پروژهٔ آموزشی با PHP، Yii 2، MySQL/MariaDB و Nginx، با رابط سادهٔ فارسی. گردش کار برای یک اپراتور است و صفحهٔ ورود یا مدیریت کاربران ندارد.

فونت یکان به‌صورت محلی از `app/web/fonts/Yekan.woff2` بارگذاری می‌شود. منبع آن [مخزن Yekan-Font](https://github.com/DediData/Yekan-Font/tree/d25d796fd4862d5e9a6426669a603807dfa3805f) است و فایل مجوز SIL Open Font License در `app/web/fonts/LICENSE.txt` قرار دارد.

## گردش کار

1. بیمار را با نام، نام خانوادگی، کد ملی ۱۰ رقمی و موبایل ۱۱ رقمی با شروع `09` ثبت کنید. ارقام فارسی و عربی در شماره‌ها به انگلیسی تبدیل می‌شوند و صفر ابتدای کد ملی حفظ می‌شود. تاریخ تولد اختیاری، به صورت میلادی `YYYY-MM-DD` و حداکثر امروز است. بررسی کد ملی در این پروژه فقط قالب آن است، نه رقم کنترل یا هویت شخص.
2. پذیرش را ثبت کنید؛ بیمار از مرحلهٔ قبل انتخاب شده است. نام پزشک و نام بخش را به صورت متن وارد کنید. تاریخ پذیرش خودکار ثبت می‌شود.
3. از خلاصهٔ پرونده «افزودن خدمت» را بزنید، یکی از خدمات از پیش تعریف‌شده و تعداد را انتخاب کنید.
4. «مشاهده هزینه و ترخیص» ریز خدمات و جمع مبلغ را نشان می‌دهد. توضیح اختیاری را وارد و ترخیص را تأیید کنید.
5. تاریخ و مبلغ ترخیص خودکار ثبت می‌شوند، وضعیت پذیرش تغییر می‌کند و خلاصهٔ پرونده نمایش داده می‌شود.

فهرست بیماران جست‌وجو بر اساس نام و کد ملی دارد. فهرست پذیرش‌ها نیز با نام بیمار، تمام یا بخشی از کد ملی و وضعیت بستری یا ترخیص‌شده فیلتر می‌شود؛ فیلترها هم‌زمان قابل استفاده‌اند. هر بیمار می‌تواند چند پذیرش داشته باشد. قیمت واحد هر خدمت هنگام ثبت ذخیره می‌شود؛ تغییر تعرفهٔ خدمات، قیمت خدمات قبلی را عوض نمی‌کند. مبلغ ترخیص در سرور از مجموع `quantity × unit_price` محاسبه می‌شود. ترخیص تکراری و ثبت خدمت پس از ترخیص مجاز نیست. بیمه، مالیات و تخفیف وجود ندارند.

## ساختار

- `app/`: کد Yii، تنظیمات، نماها و وابستگی‌های لازم اجرا.
- `database/install.sql`: نصب پنج جدول و سه خدمت نمونه برای یک دیتابیس خالی.
- `deploy/nginx.conf`: تنظیم Nginx برای اجرای ورودی `app/web/index.php`.
- `scripts/Start-Hospital.ps1`: اجرای PHP FastCGI و Nginx در ویندوز.
- `WORK_REPORT.md`: گزارش انطباق، پاک‌سازی و نتایج بررسی.

فقط پنج جدول وجود دارد: `patients`، `admissions`، `services`، `admission_services` و `discharges`. نام پزشک و بخش در جدول `admissions` ذخیره می‌شوند. اپراتور خدمات موجود را انتخاب می‌کند؛ تعریف و تغییر تعرفه‌ها از طریق دیتابیس انجام می‌شود.

## نصب تازه

PHP 8.2 یا بالاتر با افزونه‌های لازم Yii از جمله `pdo_mysql` و `mbstring`، Composer 2، MySQL/MariaDB و Nginx لازم است. مسیرهای پیش‌فرض ویندوز `C:\xampp\php` و `C:\nginx` هستند.

از ریشهٔ پروژه در PowerShell:

```powershell
composer --working-dir=app install --no-dev
New-Item -ItemType Directory -Force .\app\runtime, .\app\web\assets
```

اگر `app/config/db.php` از قبل وجود دارد، مشخصات اتصال MySQL را در همان فایل تنظیم کنید. برای نصب تازه، این فایل را با ساختار زیر بسازید و نام کاربری و رمز را با اطلاعات محلی خود جایگزین کنید. این فایل در Git ذخیره نمی‌شود.

```php
<?php
return [
    'class' => \yii\db\Connection::class,
    'dsn' => 'mysql:host=127.0.0.1;port=3306;dbname=hospital',
    'username' => 'your-local-username',
    'password' => 'your-local-password',
    'charset' => 'utf8mb4',
];
```

MySQL را روشن کنید، دیتابیس **خالی** مانند `hospital` با collation برابر `utf8mb4_unicode_ci` بسازید و `database/install.sql` را در همان دیتابیس وارد کنید. این فایل پنج جدول و خدمات نمونه را ایجاد می‌کند. فایل نصب برای دیتابیس موجود یا ارتقای آن نیست؛ آن را روی دیتابیس فعلی دوباره اجرا نکنید.

## اجرا با Nginx

مسیر `root` در `deploy/nginx.conf` را با مسیر واقعی `app/web` هماهنگ کنید. جداکنندهٔ مسیر Nginx `/` است. از تنظیم فعلی Nginx پشتیبان بگیرید و نمونه را کپی کنید:

```powershell
Copy-Item C:\nginx\conf\nginx.conf C:\nginx\conf\nginx.conf.backup
Copy-Item .\deploy\nginx.conf C:\nginx\conf\nginx.conf
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Hospital.ps1
```

MySQL باید روشن باشد. پنجرهٔ PHP را باز نگه دارید. اسکریپت تنظیم Nginx را بررسی می‌کند و PHP FastCGI را روی `127.0.0.1:9000` اجرا می‌کند. اگر این پورت اشغال باشد، نمونهٔ دوم اجرا نمی‌شود. در سیستم فعلی که برنامه در حال اجراست، نیازی به اجرای دوبارهٔ اسکریپت نیست.

[باز کردن داشبورد](http://localhost:8080/index.php?r=site/index)

برای توقف PHP در پنجرهٔ آن `Ctrl+C` بزنید. برای توقف Nginx:

```powershell
& C:\nginx\nginx.exe -p C:\nginx\ -s quit
```

خطای `502` معمولاً یعنی PHP FastCGI اجرا نیست. در خطای دیتابیس، روشن بودن MySQL و مقادیر `db.php` را بررسی کنید. در نصب تازه خدمات نمونه موجودند؛ اگر فهرست خدمات خالی است، وجود خدمات با `active=1` را در دیتابیس بررسی کنید.
